# TechGuyver tools for Claude Code and Codex

Free video, music and sound tools that run on your own Mac. Hosted version, nothing to install: https://tools.techguyverlabs.org

In Claude Code:

```
/plugin marketplace add royherma/techguyver-tools
/plugin install song-exploder@techguyver-tools
```

In Codex:

```
codex plugin marketplace add royherma/techguyver-tools
codex plugin add song-exploder@techguyver-tools
```

| Tool | What it does |
| --- | --- |
| song-exploder | Drop a song. Get every stem, the drum parts, tempo, key, chords and a MIDI file. |
| song-dna | Drop a MIDI. Get its DNA and new variations that sound like the same song. |
| videomusicmaker | Drop a talking video. Get background music written to fit what you say. |
| yapcut | Drop a talking-head take. Get an edited vertical Reel: cuts, hook title, zooms, captions, sounds and effects. |

Generated from `tools.json` in tools-site. Edit there, not here.
