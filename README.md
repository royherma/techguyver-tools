# TechGuyver tools for Claude Code

Free music tools that run on your own Mac. Hosted version, nothing to install: https://tools.techguyverlabs.org

In Claude Code:

```
/plugin marketplace add royherma/techguyver-tools
/plugin install song-exploder@techguyver-tools
```

| Tool | What it does |
| --- | --- |
| song-exploder | Drop a song. Get every stem, the drum parts, tempo, key, chords and a MIDI file. |
| song-dna | Drop a MIDI. Get its DNA and new variations that sound like the same song. |
| videomusicmaker | Drop a talking video. Get background music written to fit what you say. |

Generated from `tools.json` in tools-site. Edit there, not here.
